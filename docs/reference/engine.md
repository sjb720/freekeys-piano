# Engine — `src/renderer/engine/`

Song time is in seconds and may be negative during the lead-in. Clock time is `AudioContext.currentTime`, so visuals and audio share one clock.

| Name                                            | Signature                                         | Description                                                                                                                                                                 |
| ----------------------------------------------- | ------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Clock` / `audioClock(ctx)`                     | `{ now(): number }`                               | Time source. Tests use a fake clock.                                                                                                                                        |
| `Transport`                                     | `new (clock, { duration, start? })`               | Position from an anchor plus elapsed clock time times rate.                                                                                                                 |
| `.position()`                                   | `() => number`                                    | Current song time, clamped to `duration`.                                                                                                                                   |
| `.play()` / `.pause()` / `.toggle()`            |                                                   | Playing from the end restarts at `start`.                                                                                                                                   |
| `.seek(t)`                                      |                                                   | Clamped to `[start, duration]`.                                                                                                                                             |
| `.setRate(r)`                                   |                                                   | Clamped to `[MIN_RATE, MAX_RATE]`; position stays continuous.                                                                                                               |
| `.toClockTime(songTime)`                        |                                                   | Clock time when `songTime` plays.                                                                                                                                           |
| `.tick()`                                       |                                                   | Emits `end` and pauses at the duration.                                                                                                                                     |
| `.getState()` / `.subscribe(fn)`                |                                                   | Immutable snapshot `{ playing, rate, start, duration }` (for `useSyncExternalStore`) and events `play                                                                       | pause | seek | rate | end`. |
| `Scheduler`                                     | `new (song, transport, clock, sink, shouldPlay?)` | Lookahead scheduler: each `update()` sends notes inside the next `LOOKAHEAD` seconds to the sink exactly once. `reset()` stops sound and resumes from the current position. |
| `NoteSink`                                      | `{ play, stopAll }`                               | Implemented by `PianoSampler`.                                                                                                                                              |
| `Player`                                        | `new (song, clock, sink, onPlay?)`                | Owns a transport and scheduler, ticks every 25 ms, resets the scheduler on every non-play event. Starts at `-LEAD_IN`.                                                      |
| `.beginScrub()` / `.scrubTo(t)` / `.endScrub()` |                                                   | Drag-to-seek; resumes playback if it was playing.                                                                                                                           |
| `.restart()` / `.destroy()`                     |                                                   |                                                                                                                                                                             |
