# Engine — `src/renderer/engine/`

Song time is in seconds and may be negative during the lead-in. Clock time is `AudioContext.currentTime`, so visuals and audio share one clock.

## Transport and scheduling

| Name                                                              | Signature                              | Description                                                                                                                                                                                           |
| ----------------------------------------------------------------- | -------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Clock` / `audioClock(ctx)`                                       | `{ now(): number }`                    | Time source. Tests use a fake clock.                                                                                                                                                                  |
| `Transport`                                                       | `new (clock, { duration, start? })`    | Position from an anchor plus elapsed clock time times rate.                                                                                                                                           |
| `.position()`                                                     |                                        | Current song time, clamped to `duration` and to the gate.                                                                                                                                             |
| `.play()` / `.pause()` / `.toggle()` / `.seek(t)` / `.setRate(r)` |                                        | Seek is clamped to `[start, duration]` and rate to `[MIN_RATE, MAX_RATE]`. Playing from the end seeks back to `start` first (emits `seek`, then `play`). Position stays continuous across changes.    |
| `.setGate(t \| null)` / `.getGate()`                              |                                        | Time the transport cannot pass. Used by wait mode. Changing it re-anchors, so release doesn't jump.                                                                                                   |
| `.toClockTime(songTime)` / `.tick()`                              |                                        | Clock time for a song time; `tick` emits `end` at the duration.                                                                                                                                       |
| `.getState()` / `.subscribe(fn)`                                  |                                        | `{ playing, rate, start, duration }` snapshot and events `play`, `pause`, `seek`, `rate`, `end`.                                                                                                      |
| `EventScheduler<T extends Timed>`                                 | `new (events, transport, clock, emit)` | Lookahead scheduler: `update()` emits each event inside the next `LOOKAHEAD` seconds once, never past the gate. `reset()` resumes from the current position. Used for both notes and metronome beats. |

## Player

| Name                                                                          | Signature                                                       | Description                                                                                                                                                                                                                                                                          |
| ----------------------------------------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Player`                                                                      | `new (song, clock, audio, PlayerOptions)`                       | Owns the transport, note and beat schedulers, and the practice session. Ticks every 25 ms (loop check, practice update, scheduling). Starts at `-LEAD_IN`. Owns its `song` and rewrites `note.hand` when the hand override changes.                                                  |
| `PlayerOptions`                                                               | `{ mode, metronome, focus, otherHand, hands }`                  | `focus` is `left`/`both`/`right`; `otherHand` is `play`/`mute`; `hands` is a `HandOverride`.                                                                                                                                                                                         |
| `PlayerHooks`                                                                 | `{ onSegment?, wallNow? }`                                      | Optional fifth constructor argument.                                                                                                                                                                                                                                                 |
| `PracticeSegment`                                                             | `{ mode, focus, tempo, playTime, stats, completed, startedAt }` | One practice run, reported through `onSegment`. A run ends on a mode, focus, or hands change, a restart, the song end, or `destroy`. Runs under 10 s of playing time are dropped. `completed` means it reached the end, started from the top, never skipped ahead, and never looped. |
| `PlayerAudio`                                                                 | `{ notes: NoteSink, click(when, accent), resume() }`            | `NoteSink = { play, stopAll }` (the `PianoSampler`).                                                                                                                                                                                                                                 |
| `.getState()` / `.subscribe(fn)`                                              |                                                                 | `PlayerOptions` plus `{ loop, loopDraftStart, stats }`.                                                                                                                                                                                                                              |
| `.handleInput(event)`                                                         |                                                                 | Routes a `NoteInputEvent` to the practice session.                                                                                                                                                                                                                                   |
| `.keyFeedback()`                                                              | `ReadonlyMap<pitch, 'pressed'\|'correct'\|'wrong'>`             | Held keys and how they were judged.                                                                                                                                                                                                                                                  |
| `.setMode(mode)` / `.setFocus(focus)` / `.setHands(override)`                 |                                                                 | Each starts a fresh practice session with fresh stats.                                                                                                                                                                                                                               |
| `.setOtherHand(mode)` / `.setMetronome(on)`                                   |                                                                 | Take effect for upcoming notes.                                                                                                                                                                                                                                                      |
| `.isActive(note)` / `isNoteActive(note, focus)`                               |                                                                 | Whether a note belongs to the focused hand(s).                                                                                                                                                                                                                                       |
| `.cycleLoop()`                                                                |                                                                 | Off → loop start at this measure → loop end at this measure (seeks to start) → off.                                                                                                                                                                                                  |
| `.beginScrub()` / `.scrubTo(t)` / `.endScrub()` / `.restart()` / `.destroy()` |                                                                 | Restart goes to the loop start if a loop is set, and resets stats.                                                                                                                                                                                                                   |

Sound: watch mode plays everything. In practice modes the app never plays the focused hand's notes; the other hand plays when `otherHand` is `play`. Notes already scheduled keep sounding while wait mode holds.

## Practice (`engine/practice/`)

| Name                          | Signature                                        | Description                                                                                                                                                                                                                                       |
| ----------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `buildSteps(notes, isActive)` | `=> Step[]`                                      | Groups active notes starting within `CHORD_WINDOW` (50 ms) into chords.                                                                                                                                                                           |
| `WaitMode`                    | `new (steps)`                                    | `gate()` is the current step's start. `onNoteOn(pitch, position, rate)` returns `correct` / `wrong` / `ignored` (a repeat). A step is complete when every pitch is hit after arming (`EARLY_WINDOW` = 0.3 s × rate before it). `reset(position)`. |
| `PlayAlongGrader`             | `new (activeNotes)`                              | `onNoteOn` matches the nearest unmatched same-pitch note within `HIT_WINDOW` (150 ms real time); `collectMisses(position, rate)` counts unmatched notes once they leave the window.                                                               |
| `PracticeSession`             | `new (mode, song, transport, isActive, onStats)` | Mode-specific judging, gate control, key feedback, and `PracticeStats { hits, misses, wrong, accuracy }`. `reset()` on seek; `dispose()` releases the gate.                                                                                       |

## Loops

| Name                       | Signature           | Description                                                                     |
| -------------------------- | ------------------- | ------------------------------------------------------------------------------- |
| `loopStartAt(song, t)`     | `=> number`         | Start of the measure containing `t`.                                            |
| `loopFrom(song, start, t)` | `=> { start, end }` | Ends at the end of `t`'s measure, and always covers at least the start measure. |
