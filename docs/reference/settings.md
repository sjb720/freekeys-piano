# Settings

Registry: `src/shared/settings`, documented in `shared.md`.
Store: `src/renderer/state/settingsStore.ts`, documented in `state.md`.
UI: `src/renderer/features/settings`, documented in `features.md`.
Storage: `settings` table in main (`Profiles`), scoped by `layer`. `app` settings are shared on the device; `profile` settings belong to the active profile.
