# Shared — `src/shared/`

Pure TypeScript used by main and renderer. No DOM, Node, or Electron imports.

## `song/` (`@shared/song`)

| Name                                                                                                   | Signature                                                   | Description                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------------------------------------------------------------------------------------------------ | ----------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `parseMidi`                                                                                            | `(bytes, fallbackTitle) => Song`                            | Parses a MIDI file, drops percussion, sorts notes, merges the same key struck by two tracks within `SLICE_WINDOW` (keeping the longer duration), assigns hands (`handsByTrack` then `repairReach`, else `separateHands`), and computes measures, beats, and metadata. Sets `handSource` and each note's `autoHand`. The title is the embedded sequence name unless it's a placeholder (`isPlaceholderTitle`) or, in a format 1 file, the name of a track that has notes; then `fallbackTitle`. Track names and the title go through `decodeMidiText`. |
| `handsByTrack`                                                                                         | `(TrackSummary[], TrackNote[]) => Map<track, Hand> \| null` | Uses names when every track is named and both hands appear (`right/RH/treble/up/upper`, `left/LH/bass/down/lower`, with LilyPond suffixes like `upII`). Otherwise, exactly two tracks split by mean pitch. Three or more go to `handsByPlayability`, with any named tracks fixed.                                                                                                                                                                                                                                                                     |
| `handsByPlayability`                                                                                   | `(tracks, notes, fixed?) => Map<track, Hand> \| null`       | Tries every left/right split of up to 8 unfixed tracks. Each onset slice costs its span beyond `REACH` (a tenth) per hand, notes beyond `MAX_NOTES`, and left-over-right crossing; a small pull toward C3/C5 breaks ties. Returns `null` when the best split leaves more than `MAX_UNPLAYABLE` (5%) of onsets unplayable.                                                                                                                                                                                                                             |
| `repairReach`                                                                                          | `(notes) => moved count`                                    | Per onset slice, gives a hand's outermost note to the other hand while its chord is wider than `REACH` and the other hand can take it. Mutates `hand`.                                                                                                                                                                                                                                                                                                                                                                                                |
| `separateHands`                                                                                        | `(notes sorted by start) => Hand[]`                         | Heuristic for single-track or ambiguous files. Groups onsets within `SLICE_WINDOW` (30 ms) and picks the cheapest low/high split per slice. The cost covers distance from each hand's running position (starting at C3 and C5), span beyond `MAX_SPAN` (a 9th, including held notes), more than `MAX_NOTES` (5) per hand, and crossing the other hand's held notes. Each hand's position then moves 40% toward the notes it was given.                                                                                                                |
| `resolveHand` / `HandOverride` / `AUTO_HANDS`                                                          | `(note, override) => Hand`                                  | Override kinds: `auto` (`autoHand`), `split` at a pitch (inclusive right), `swap`, `tracks` (`hands` maps track index to hand; unlisted tracks keep `autoHand`).                                                                                                                                                                                                                                                                                                                                                                                      |
| `handsByMajority`                                                                                      | `(notes) => Record<track, Hand>`                            | Each track's hand by majority of its notes' `autoHand`. Starting point for a `tracks` override.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `decodeMidiText` / `isPlaceholderTitle`                                                                | `(raw) => string` / `(title) => boolean`                    | Re-decodes byte-per-char meta text as UTF-8 when valid and strips control characters. Placeholders: `control track`, `Track 1`, `Untitled`, text with no letters or digits, and similar.                                                                                                                                                                                                                                                                                                                                                              |
| `firstTrackHasNotes` / `midiFormat` / `midiTrackCount`                                                 | `(bytes) => boolean` / `number`                             | Raw header and first-chunk reads (`rawMidi.ts`), since `@tonejs/midi` moves meta events and notes into separate tracks. Not exported from the index.                                                                                                                                                                                                                                                                                                                                                                                                  |
| `noteName` / `pitchClassName`                                                                          | `(pitch) => string`                                         | `60 → 'C4'` / `61 → 'C#'`, using sharps.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `handBySplit`                                                                                          | `(pitch) => Hand`                                           | Fallback split at `SPLIT_PITCH` (middle C).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `measureStartTicks`                                                                                    | `(signatures, endTicks, ppq) => number[]`                   | Measure start ticks across time-signature changes; defaults to 4/4.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `lowerBound`                                                                                           | `(items: Timed[], time) => index`                           | First item with `start >= time`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `measureIndexAt` / `measureBounds`                                                                     | `(song, time)` / `(song, index)`                            | Measure containing a time; a measure's `{ start, end }`, where the last one ends at `duration`.                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `beatTicks`                                                                                            | `(signatures, endTicks, ppq) => TickBeat[]`                 | Beat ticks with downbeat flags. Beat length follows the denominator.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `forEachNoteInWindow`                                                                                  | `(song, from, to, visit)`                                   | Visits notes overlapping `[from, to)`, including long notes that started earlier.                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| `Song`, `SongTrack`, `Note`, `Beat`, `Hand`, `HandSource`, `Timed`, `TempoEvent`, `TimeSignatureEvent` | types                                                       | `song.tracks` lists note tracks (`index`, `name`, `instrument`, `noteCount`, `minPitch`, `maxPitch`); `note.track` is the same index. Times are in seconds; `notes` sorted by start then pitch; `id` is the sorted index; `note.hand` is the effective hand and `note.autoHand` the detected one; `handSource` is `tracks` or `heuristic`; `beats` drive the metronome.                                                                                                                                                                               |

## `settings/` (`@shared/settings`)

| Name                 | Signature                    | Description                                                                                         |
| -------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------- |
| `SETTINGS`           | registry                     | Every setting: `layer` (`app`/`profile`), `section`, `label`, `description?`, `default`, `control`. |
| `SETTING_SECTIONS`   | `readonly string[]`          | Section order on the settings page.                                                                 |
| `SETTING_KEYS`       | `SettingKey[]`               | All keys.                                                                                           |
| `defaultSettings`    | `() => SettingValues`        | Defaults for every key.                                                                             |
| `formatSettingValue` | `(control, value) => string` | Display text for a value (`80%`, `2.5 s`).                                                          |

Controls: `slider` (`min/max/step/format`), `segmented` (`options`), `toggle`, `theme` (options from the theme registry), `midiDevice` (options from connected devices).

`PRACTICE_MODES` / `PracticeMode` / `PRACTICE_MODE_LABELS`: `watch`, `playAlong`, `wait`.

`HAND_FOCUSES` / `HandFocus` / `HAND_FOCUS_LABELS`: `left`, `both`, `right`. `OTHER_HAND_MODES` / `OtherHandMode`: `play`, `mute`. `KEY_LABEL_MODES` / `KeyLabelMode`: `off`, `c`, `white`, `all`.

`isValidSettingValue(key, value)` checks a stored value against the registry: known key, same type as the default, a listed segmented option, and slider range. `settingKeysFor(layer)` lists the keys of one layer.

### Adding a setting

1. Add an entry to `SETTINGS`.
2. Read it with `useSetting(key)`. The settings page picks it up automatically.

## `analysis/`

| Name                      | Signature                                        | Description                                                                                                                                                                                                                                                                                                        |
| ------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `analyzeDifficulty`       | `(song) => Difficulty`                           | Per-hand scores (0 to 100) from `handFeatures`. Each feature is normalized between its `SCALES` easy and hard values, then weighted. Overall score = 0.65 × hardest hand + 0.35 × easiest hand + 12 × `handIndependence`. `level` is 1 to 10 (`levelFor`). `factors` are the top 4 contributions of at least 0.03. |
| `ANALYSIS_VERSION`        | `number`                                         | Bump when scoring changes. The library re-analyzes older rows on the next scan.                                                                                                                                                                                                                                    |
| `SCALES`                  | `Record<feature, { easy, hard, weight, label }>` | Calibration table. Weights sum to 1.                                                                                                                                                                                                                                                                               |
| `handFeatures`            | `(notes of one hand, beats) => HandFeatures`     | `peakRate` (most notes in any 2 s window, per second), `meanRate` (notes per second of playing time, gaps capped at 1.5 s), `chordSize`, `maxPolyphony`, `span` and `leap` (90th percentile, semitones), `range`, `blackKeys` ratio, `offGrid` (onsets off the eighth-note grid).                                  |
| `handIndependence`        | `(notes) => 0..1`                                | Share of onsets where only one hand plays.                                                                                                                                                                                                                                                                         |
| `summarizeSong`           | `(bytes, fallbackTitle, hands?) => SongSummary`  | Parses, applies an optional `HandOverride`, and rates the song. `SongSummary = { title, duration, noteCount, handSource, difficulty }`.                                                                                                                                                                            |
| `levelFor` / `percentile` |                                                  | Helpers.                                                                                                                                                                                                                                                                                                           |
