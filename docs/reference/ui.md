# UI primitives — `src/renderer/ui/`

The only place raw interactive/text elements are allowed (enforced by `piano/no-raw-elements`). Components take no `className`/`style`; extend via props.

Shared types: `Space` = `none`, `xs`, `sm`, `md`, `lg`, `xl`; `Variant` = `primary`, `secondary`, `ghost`, `danger`; `ControlSize` = `md`, `lg`; `Tone` = `neutral`, `accent`, `success`, `warning`, `danger`.

| Component             | Key props                                                                                                | Description                                                                                                                                                                                                  |
| --------------------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `Button`              | `variant='secondary'`, `size='md'`, `icon?`, `fullWidth?`, native button attrs                           | Touch-sized labeled button. `lg` for primary actions.                                                                                                                                                        |
| `IconButton`          | `icon`, `label` (required, used for aria-label/title), `variant='ghost'`, `size`                         | Round icon-only button.                                                                                                                                                                                      |
| `Icon`                | `icon: LucideIcon`, `size='md'` (`sm`, `md`, `lg`)                                                       | Decorative icon, inherits text color.                                                                                                                                                                        |
| `Stack`               | `direction='column'`, `gap='md'`, `padding='none'`, `align`, `justify`, `wrap`, `grow`, `scroll`         | Flex layout primitive. `grow` fills remaining space; `scroll` makes it scrollable.                                                                                                                           |
| `Text`                | `variant='body'` (`display`, `title`, `heading`, `body`, `caption`), `tone`, `align`, `as?`, `truncate?` | All text. Variant picks a semantic tag; override with `as`.                                                                                                                                                  |
| `Slider`              | `label`, `value`, `min`, `max`, `step=1`, `size='full'` (`sm`, `md`, `full`), `onChange`, `onCommit?`    | Touch-sized range input; the filled track shows the value. `onChange` fires while dragging, `onCommit` once on release (or per key step).                                                                    |
| `Field`               | `label`, `description?`, `value?`, `trailing?`, `children?`                                              | Label row (with value text or a `trailing` control), optional description, then the control.                                                                                                                 |
| `Toggle`              | `label`, `checked`, `onChange`                                                                           | On/off switch (`role=switch`).                                                                                                                                                                               |
| `ListItem`            | `title`, `subtitle?`, `icon?`, `trailing?` (defaults to chevron), `onPress`                              | Full-width pressable row.                                                                                                                                                                                    |
| `TextField`           | `label`, `value`, `onChange`, `placeholder?`, `icon?`, `type='text'` (`text`, `search`)                  | Pill-shaped text input with a leading icon and a clear button.                                                                                                                                               |
| `Badge`               | `tone='neutral'`, `size='md'` (`md`, `lg`), `children`                                                   | Outlined pill in the tone color.                                                                                                                                                                             |
| `Meter`               | `label`, `value` (0 to 1), `tone='accent'`                                                               | Read-only bar (`role=meter`).                                                                                                                                                                                |
| `Stat`                | `label`, `value`, `caption?`                                                                             | Stat tile: label, large tabular value, muted caption. Flexes in a wrapping row.                                                                                                                              |
| `BarChart`            | `label`, `bars: { key, tick, value, detail, labeled? }[]`, `valueText`                                   | Single-series column chart in `accent`: 4px rounded tops, 2px gaps, values only on `labeled` bars. Hover, focus, or tap shows a bar's `detail` above the plot; a tap's readout stays after the finger lifts. |
| `Avatar`              | `icon`, `color?: ColorToken`, `size='md'` (`sm`, `md`, `lg`, `xl`), `label?`, `onPress?`                 | Rounded square with an icon in `avatarInk` on `color`. Without `color`, a dashed neutral style. Renders a button when `onPress` is set.                                                                      |
| `Tile`                | `label`, `onPress`, `children`, `overlay?`                                                               | Large pressable visual with a caption below; `overlay` covers the visual (e.g. an edit icon).                                                                                                                |
| `SeekArea`            | `label`, `onSeek(fraction)`, `hint?(fraction)`, `children`                                               | Full-width button over a timeline. Seeks on release (0..1), so touch can press and slide to preview; mouse shows the line on hover. Vertical swipes still scroll. Keyboard activation gives 0.               |
| `ChoiceGrid<T>`       | `label`, `options: { value, label, content }[]`, `value`, `onChange`                                     | Wrapping radio group of visual choices; the selected one gets an accent ring.                                                                                                                                |
| `Sheet`               | `title`, `open`, `onClose`, `children`                                                                   | Modal panel in a portal over an `overlay` backdrop. Closes on Escape, a backdrop click or tap that also started on the backdrop, or the close button.                                                        |
| `DropOverlay`         | `visible`, `label`, `icon?`                                                                              | Full-window dashed drop target shown while files are dragged over the app. Ignores pointer events.                                                                                                           |
| `Chip`                | `label`, `selected`, `onPress`, `icon?`, `count?`                                                        | Pill toggle (`aria-pressed`) with an optional count; accent fill when selected. For quick filters.                                                                                                           |
| `Card`                | `gap='lg'`, `children`                                                                                   | Bordered `surface` panel with a padded column of children.                                                                                                                                                   |
| `SegmentedControl<T>` | `label`, `options: {value,label,icon?}[]`, `value`, `onChange`                                           | Single-choice radio group rendered as segments.                                                                                                                                                              |

Shared styles: `interactive.module.css` (base + variant classes used by every pressable component).
