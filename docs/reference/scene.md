# Scene (PixiJS) — `src/renderer/scene/`

Imperative Pixi classes driven by the Pixi ticker. React only calls setters. Colors come from `PixiPalette` (`themes/pixiTheme`).

| Name                                                | Signature                                                                                                             | Description                                                                                                                                                                                                                                                                                                                                                                                                                |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PianoScene`                                        | `new (app, { song, position, keyStates, isActive, markers, onKey, palette, fallTime, keyLabels, noteLabels, scrub })` | Lays out the highway and keyboard on resize and renders every frame. Keys light in the hand color for sounding notes; `keyStates()` (`pressed`/`correct`/`wrong` → `keyPressed`/`keyCorrect`/`keyWrong`) overrides that. Notes where `isActive` is false draw at 30% alpha. `markers()` draws loop lines. Drag on the highway scrubs. `setPalette`, `setFallTime`, `setKeyLabels`, and `setNoteLabels` update it live.     |
| `.setPalette(p)` / `.setFallTime(s)` / `.destroy()` |                                                                                                                       |                                                                                                                                                                                                                                                                                                                                                                                                                            |
| `NoteHighway`                                       | `new (noteTexture)`                                                                                                   | Pooled sprites for octave lanes, measure lines, notes, note labels, and loop markers. `layout(keys, area, palette)` on resize; `render(HighwayFrame)` every frame with `{ song, position, fallTime, keys, area, palette, markers, isActive, labels }`. Notes where `isActive` is false draw at 30% alpha. With `labels`, notes show `BitmapText` names (`noteLabel` token) at their bottom edge when `noteLabelSize` fits. |
| `noteLabelSize`                                     | `(text, width, height) => number \| null`                                                                             | Font size for a note label: up to 14 px, scaled to the note width, or `null` below 8 px or when the note is too short.                                                                                                                                                                                                                                                                                                     |
| `PianoKeyboard`                                     | `new (palette, onKey, labelMode='off')`                                                                               | One sprite per key. `build(layout, height)`; `setActive(Map<pitch, ColorToken>)` re-tints only changed keys; `setLabelMode(mode)` redraws note labels (`keyLabel` / `keyLabelOnBlack` tokens). Multi-touch: `onKey(pitch, down)` per pointer.                                                                                                                                                                              |
| `labelFor`                                          | `(pitch, black, KeyLabelMode) => string \| null`                                                                      | `off`, `c` (C keys only), `white`, `all`. C keys show their octave (`C4`); others show the letter (`D`, `F#`).                                                                                                                                                                                                                                                                                                             |
| `installNoteLabelFont` / `NOTE_LABEL_FONT`          | `labels.ts`                                                                                                           | Installs the bitmap font for note labels (A–G, #, 0–9) once.                                                                                                                                                                                                                                                                                                                                                               |
| `fitKeyRange`                                       | `(min, max, minKeys=25, margin=2) => { low, high }`                                                                   | Visible range snapped to whole octaves (C to B), clamped to 88 keys.                                                                                                                                                                                                                                                                                                                                                       |
| `layoutKeys`                                        | `(range, width) => KeyLayout`                                                                                         | Key rects: whites evenly spaced, blacks centered on boundaries. `keys` is in draw order (whites first); `byPitch` is an index.                                                                                                                                                                                                                                                                                             |
| `isBlackKey`                                        | `(pitch) => boolean`                                                                                                  |                                                                                                                                                                                                                                                                                                                                                                                                                            |

The highway's y position is `bottom - (time - position) / fallTime * height`.
