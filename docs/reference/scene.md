# Scene (PixiJS) — `src/renderer/scene/`

Imperative Pixi classes driven by the Pixi ticker. React only calls setters. Colors come from `PixiPalette` (`themes/pixiTheme`).

| Name                                                | Signature                                                                                                 | Description                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------------------------------------- | --------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `PianoScene`                                        | `new (app, { song, position, keyStates, isActive, markers, onKey, palette, fallTime, keyLabels, scrub })` | Lays out the highway and keyboard on resize and renders every frame. Keys light in the hand color for sounding notes; `keyStates()` (`pressed`/`correct`/`wrong` → `keyPressed`/`keyCorrect`/`keyWrong`) overrides that. Notes where `isActive` is false draw at 30% alpha. `markers()` draws loop lines. Drag on the highway scrubs. `setPalette`, `setFallTime`, and `setKeyLabels` update it live. |
| `.setPalette(p)` / `.setFallTime(s)` / `.destroy()` |                                                                                                           |                                                                                                                                                                                                                                                                                                                                                                                                       |
| `NoteHighway`                                       | `new (noteTexture)`                                                                                       | Pooled rounded note sprites (nine-slice), measure lines, octave lanes, and marker lines. `layout(keys, area, palette)` on resize; `render(song, position, fallTime, keys, area, palette, markers?)` per frame.                                                                                                                                                                                        |
| `PianoKeyboard`                                     | `new (palette, onKey, labelMode='off')`                                                                   | One sprite per key. `build(layout, height)`; `setActive(Map<pitch, ColorToken>)` re-tints only changed keys; `setLabelMode(mode)` redraws note labels (`keyLabel` / `keyLabelOnBlack` tokens). Multi-touch: `onKey(pitch, down)` per pointer.                                                                                                                                                         |
| `labelFor`                                          | `(pitch, black, KeyLabelMode) => string \| null`                                                          | `off`, `c` (C keys only), `white`, `all`. C keys show their octave (`C4`); others show the letter (`D`, `F#`).                                                                                                                                                                                                                                                                                        |
| `fitKeyRange`                                       | `(min, max, minKeys=25, margin=2) => { low, high }`                                                       | Visible range snapped to whole octaves (C to B), clamped to 88 keys.                                                                                                                                                                                                                                                                                                                                  |
| `layoutKeys`                                        | `(range, width) => KeyLayout`                                                                             | Key rects: whites evenly spaced, blacks centered on boundaries. `keys` is in draw order (whites first); `byPitch` is an index.                                                                                                                                                                                                                                                                        |
| `isBlackKey`                                        | `(pitch) => boolean`                                                                                      |                                                                                                                                                                                                                                                                                                                                                                                                       |

The highway's y position is `bottom - (time - position) / fallTime * height`.
