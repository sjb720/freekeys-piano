# Input — `src/renderer/input/`

Every source emits `NoteInputEvent { type: 'on'|'off', pitch, velocity (0..1), source: 'midi'|'touch'|'mic' }` into one hub. Consumers never care which source produced an event. Pedals arrive separately as `PedalInputEvent { pedal: 'sustain'|'sostenuto'|'soft', down, source }`.

| Name                                                | Signature                               | Description                                                                                                                                                                                |
| --------------------------------------------------- | --------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `inputHub`                                          | `InputHub` singleton                    | App-wide event bus.                                                                                                                                                                        |
| `InputHub.emit(event)`                              |                                         | Tracks held notes. Drops note-off for notes that aren't held.                                                                                                                              |
| `InputHub.subscribe(fn)`                            | `=> unsubscribe`                        |                                                                                                                                                                                            |
| `InputHub.subscribePedal(fn)` / `.emitPedal(event)` | `=> unsubscribe`                        | Pedal events. `MidiInput` emits them; the player listens when the `pedalControl` setting picks a pedal.                                                                                    |
| `InputHub.heldNotes()`                              | `ReadonlyMap<pitch, source>`            |                                                                                                                                                                                            |
| `InputHub.releaseSource(source)`                    |                                         | Emits note-off for every held note from that source (e.g. device unplugged, page left).                                                                                                    |
| `midiInput`                                         | `MidiInput` singleton                   | Web MIDI source. `start()` requests access once; hot-plug via `onstatechange`.                                                                                                             |
| `MidiInput.setDevice(id)`                           | `'all'` or device id                    | Which inputs to listen to.                                                                                                                                                                 |
| `MidiInput.getDevices()` / `.subscribe(fn)`         |                                         | Connected devices, for `useSyncExternalStore`.                                                                                                                                             |
| `parseMidiMessage(data)`                            | `=> MidiMessage \| null`                | Note on/off on any channel (velocity-0 note-on counts as off), and control changes 64/66/67 as `{ type: 'pedal', pedal, down }` with down at value 64 or more. Everything else is ignored. |
| `useMidiInputSync()`                                | hook                                    | Starts MIDI and applies the `midiInput` setting. Mounted once in `App`.                                                                                                                    |
| `useMidiDevices()`                                  | `=> MidiDevice[]`                       |                                                                                                                                                                                            |
| `PedalTaps`                                         | `new (onTap, windowMs = DOUBLE_TAP_MS)` | `update(down, now)` fires `'single'` on every press and `'double'` when a press follows the last within 400 ms. Repeated down values (half-pedal) are ignored.                             |

Touch input comes from `PianoKeyboard` in the scene, which `SongStage` forwards to `inputHub` with `source: 'touch'`. Touch notes also sound through the sampler; MIDI notes don't, because the keyboard makes its own sound.

Electron only grants the `midi` and `midiSysex` permissions (`src/main/permissions.ts`). Chromium requests `midiSysex` for every `requestMIDIAccess()` call, so granting only `midi` silently blocks all MIDI input. A failed `MidiInput.start()` logs `MIDI access failed`.
