# Main process — `src/main/`

| Name                               | File             | Description                                                                                                                                                             |
| ---------------------------------- | ---------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `createMainWindow()`               | `window.ts`      | Sandboxed, context-isolated window with autoplay allowed. Blocks in-app navigation; https links open externally. Loads the dev server URL or `app://bundle/index.html`. |
| `registerSchemePrivileges()`       | `protocol.ts`    | Registers `app://` as standard/secure/fetch-capable. Must run before `ready`.                                                                                           |
| `serveDirectory(root)`             | `protocol.ts`    | Serves files from `root` over `app://`, rejecting path traversal.                                                                                                       |
| `resourcesDir()` / `rendererDir()` | `paths.ts`       | Bundled resources (`resources/` in dev, `process.resourcesPath` when packaged) and the built renderer.                                                                  |
| `registerHandlers(library)`        | `handlers.ts`    | Registers all IPC handlers, including the file and folder dialogs.                                                                                                      |
| `configurePermissions()`           | `permissions.ts` | Grants only `midi`; denies every other permission request.                                                                                                              |

## `library/`

| Name                           | File               | Description                                                                                                                                                                                                                                                                                                          |
| ------------------------------ | ------------------ | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `Library`                      | `Library.ts`       | `new ({ dbPath, bundledDir, runner, onStatus })`. Facade over the database and scanner. Roots are `bundledDir` plus every library folder. Methods: `list`, `get`, `folders`, `addFolder` (starts a scan), `removeFolder`, `importFile(path)`, `load(id)`, `setFavorite`, `setHands` (re-analyzes in place), `close`. |
| `LibraryDb`                    | `LibraryDb.ts`     | `node:sqlite` store with tables `folders`, `songs` (summary, difficulty JSON, `analysis_version`, favorite, hands), and `files` (path → song, source, folder, mtime, size; `song_id` null for unreadable files). A song's source is its best file: bundled, then library, then file.                                 |
| `Scanner`                      | `Scanner.ts`       | `scan()` walks each root, deletes rows for missing files, and queues new or changed files (by mtime and size) plus songs below `ANALYSIS_VERSION`. Results commit in batches of 50 with a status update each. Calls during a scan queue one more pass. `changed()` bumps `revision`.                                 |
| `walkMidi(dir)`                | `Scanner.ts`       | Recursive `.mid`/`.midi` finder with mtime and size.                                                                                                                                                                                                                                                                 |
| `AnalyzeRunner`                | `Scanner.ts`       | `(paths, overrides, onResult) => Promise<void>`. Tests run it inline.                                                                                                                                                                                                                                                |
| `runInUtilityProcess`          | `utilityRunner.ts` | Production runner. Forks `libraryWorker.js` (`worker.ts`) for each scan.                                                                                                                                                                                                                                             |
| `analyzeFile(path, overrides)` | `analyzeFile.ts`   | Reads, hashes (`songIdFor`), and summarizes one file. Returns `{ path, id, summary }` or `{ path, error }`.                                                                                                                                                                                                          |
| `titleFromPath`                | `analyzeFile.ts`   | Fallback title when the MIDI has no name.                                                                                                                                                                                                                                                                            |

The database is `library.db` in Electron's `userData` directory (`libraryDbPath`).

`scripts/generate-demos.mts` (`pnpm demos`) builds the demo MIDIs from note lists.
